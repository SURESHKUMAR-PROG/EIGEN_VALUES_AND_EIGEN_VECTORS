Theory: Eigenvalues and Eigenvectors

1. Introduction
Eigenvalues and eigenvectors are important concepts in linear algebra used to study linear transformations. They help in understanding how a matrix transforms a vector, mainly by scaling it without changing its direction.

2. Definition (with Example)

Let A be any given square matrix, a real number λ is said to be eigenvalue of matrix A of order n × n corresponding to non zero eigen vector X iff:

AX = λX

where:

  • A = given square matrix
  • X = eigenvector (non-zero vector)
  • λ (lambda) = scalar called the eigenvalue

3. Characteristic Equation

Eigenvalues are obtained using:

AX = λX
AX − λX = 0
(A − λI)X = 0

For a non-trivial solution (X ≠ 0), determinant must be zero:

|A − λI| = 0
  • This is called the characteristic equation
  • The roots of this equation are eigenvalues

Characteristic equation:

λ² − (trace A)λ + |A| = 0

where:

  • trace A = sum of diagonal elements
  • |A| = determinant of matrix

(b) For 3 × 3 Matrix

λ³ − (trace A)λ² + (M₁₁ + M₂₂ + M₃₃)λ − |A| = 0

where:

  • trace A = sum of diagonal elements
  • M₁₁, M₂₂, M₃₃ = minors of diagonal elements

5. Eigenvectors

Eigenvectors are obtained by solving:

(A − λI)X = 0
  • It forms a homogeneous system of equations
  • It has non-trivial (infinite) solutions

6. Properties

1. Trace Property

The sum of all eigenvalues equals the trace of the matrix:

∑ λᵢ = tr(A) = ∑ aᵢᵢ

2. Determinant Property

The product of all eigenvalues equals the determinant:

∏ λᵢ = det(A)

3. Linear Independence

Eigenvectors corresponding to different eigenvalues are linearly independent.

4. Spectral Theorem

If matrix A is symmetric, then:

  • All eigenvalues are real
  • Eigenvectors are orthogonal
  • They form a basis for ℝⁿ

5. Diagonalization

If a matrix has n linearly independent eigenvectors, then:

A = PDP⁻¹

where:

  • D = diagonal matrix of eigenvalues
  • P = matrix of eigenvectors

Real-World Applications

Principal Component Analysis (PCA)

PCA uses eigenvectors of a covariance matrix to identify patterns in high-dimensional data.

Google PageRank

The importance of webpages is calculated as the dominant eigenvector of the web link matrix.

Structural Engineering

Bridges and skyscrapers have "natural frequencies" (eigenvalues) that engineers must account for.

Machine Learning

Eigenvectors are used in facial recognition, recommender systems, and clustering algorithms.

Quantum Mechanics

Observables are Hermitian operators whose eigenvalues represent measurement outcomes.

Network Analysis

Eigenvalues of adjacency matrices reveal connectivity, centrality, and community structure.
